# Мой день

Личный трекер дня: распорядок, дневник, список покупок и учёт калорий — в одном приложении, полностью в браузере, без сервера.

## Возможности

- **Распорядок дня** — расписание с настройкой по дням недели, отметка выполненных задач
- **Дневник** — мысли дня и инсайты
- **Покупки** — список продуктов и вещей с разбивкой по местам покупки, отметка купленного
- **Питание** — учёт калорий и БЖУ с целями на день
- Тёмная и светлая тема
- Экспорт и импорт данных в JSON
- Работает офлайн, можно добавить на главный экран телефона

## Технологии

Vanilla JavaScript, HTML, CSS. Все данные хранятся локально в браузере (localStorage), без внешнего бэкенда.
